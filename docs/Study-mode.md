# Optional study mode

Open Pi and Obsidian, finish any active quiz, then type `/lock <lesson goal>` at Pi's normal prompt. The Windows guard pins the terminal left and Obsidian right. It does not run automatically when you install or start the workspace.

`/lock status` shows the agreed goal and passed checks. `/test` requests the final test. Normal release requires three distinct fresh foundation, application and transfer quizzes, each with a correct submitted answer and your own sound reasoning. Pi reviews the actual attempt IDs. A miss receives focused repair and a replacement for that check. Passing all three releases normally; it does not add another test.

Emergency recovery: **Ctrl+Alt+Shift+L**. Automatic release also occurs after 90 minutes, loss of Pi's heartbeat for 30 seconds, or closure of a required window. An interrupted release never records mastery. Window placement and controls are restored.

This voluntary foreground guard is not a tamper-proof OS kiosk. It leaves other apps open and does not block the secure Windows screen or Task Manager. Model judgment of a reasoning note can be mistaken; ambiguous dictation must be clarified before grading. The guard should identify the learning terminal from its title; if multiple terminals make identification ambiguous, close the others before starting it.
