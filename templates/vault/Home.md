# Learning workspace

Open Pi beside this vault. Type `/login` to connect your own AI account, choose an available model with `/model`, then `/learn <your goal>`.

Pi probes relevant foundations, verifies sources, asks you to approve a small dependency map, and teaches one connection at a time. Explain your reasoning in quiz notes. F4 starts/stops local dictation; review the words before submitting.

- [[Learner Profile]] — your course, goals and constraints
- [[Current Lesson]] — the latest lesson, written automatically
- [[Lesson Map]] — the agreed plan and current node
- [[Review Queue]] — retrieval practice based on saved evidence
- [[Sessions]] — lesson history

Put class notes in `Sources/Class Materials`, then use `/materials` in Pi. `/lock` is optional and starts only when you request it; read the repository's study-mode documentation first.
