# Learning workspace

Open Pi beside this vault. Type `/login` to connect an AI account, choose an available model with `/model`, then `/learn <your goal>`.

Pi probes relevant foundations, verifies sources, asks you to approve a small dependency map and teaches one connection at a time. Explain your reasoning in quiz notes. On Windows, F4 starts/stops local English dictation; review the words before submitting.

- [[Learner Profile]] — optional goals, language, experience and constraints
- [[Current Lesson]] — the latest lesson, written automatically
- [[Lesson Map]] — the agreed plan and current node
- [[Review Queue]] — retrieval practice based on saved evidence
- [[Sessions]] — lesson history

Put relevant notes and documents in `Sources/Class Materials`, then use `/materials` in Pi. They can be course, work or self-study sources. Windows `/lock` is optional and starts only when requested; read the repository's study-mode documentation first.
